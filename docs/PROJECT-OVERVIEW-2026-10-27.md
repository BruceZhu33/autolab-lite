## 一、一句话

**AutoLab = 个人研究者的自主 GPU 实验台:GLM Agent 在你的真实工程上自主迭代实验,
Python 只管证据与硬约束,关键决策留给人。**

- 研究者登记自己的工程（代码在自有 GPU 服务器上）
- Agent 自己读代码、改代码、跑实验、对照基线判定是否提升
- 人只在四个门口出现:确认基线、看轮次报告、采纳成果、开新方向
- 每一步有证据:指标是真实评测出来的,判定由 Python 对照基线算,不信 Agent 自述

## 三、核心设计:阶段 workflow × 阶段内 Agent Loop

```
阶段(Python 管,确定性事实)      立项 ──▶ Baseline ──▶ 研究
                                  │          │           │
阶段内(Agent 管,开放问题)       无 agent   Agent 会话   Agent 会话(轻/中/重三档)
                                             ↑           ↑
                                  同一个 AgentLoop 运行时,不同提示词/工具面/退出条件
```

AgentLoop 运行时(`agent/runtime.py`):会话只有 6 个状态,「等人」和「等 GPU」是同一类
暂停——Job 结束后指标和失败日志尾部作为工具结果塞回会话继续;messages 每步落库,
重启自动续跑。Python 只做 Agent 不该决定的事:**验收**(finish 后核验)、**判定提升**
(逐 Job 对照数据集基线)、**硬顶**(步数/tokens/轮数/GPU 小时)、**公平对比纪律**。

## 四、研究闭环(2026-10-26/27 补全后的完整链路)

```
①重型迭代(过夜) ──▶ ②均值判定+冠军 ──▶ ③飞书通知 ──▶ ④全量验证(一键)
   Agent 自主改码/跑实验      变体 n≥3 seed 均值          你拍板后:不改代码,
   多轮翻篇(journal 记忆)     ≥阈值才停;跨轮冠军追踪       全数据集×N seed 重跑
                                                                        │
⑦分叉新方向(可选) ◀──⑥采纳为新基线 ◀──────── ⑤逐数据集结论表(✓/~//✗)────┘
   worktree 秒级检出旧基线     实测均值覆盖快照,旧版入历史,
   数据/权重零拷贝共享         下一轮自动对比新基线
```

各环的信任设计:

| 环节 | 人做什么 | 机器保证什么 |
|---|---|---|
| 迭代 | 给一句话想法,或不给 | 公平对比硬规则(口径一致/不改评测/失败也是结论);dataset 标注与命令身分参数校验,错标提交即拒 |
| 判定 | 不在场 | 多 seed 均值口径(单 seed 冒尖不算);冠军跨轮追踪,通知指向真冠军 |
| 验证 | 研究页点一下「全量验证」 | 验证会话只读工具面(无改码/shell),跑的就是当时的工作区 |
| 采纳 | 点「采纳为新基线」 | 全指标均值覆盖+旧版入 history+研究日志留痕;未通过也可 owner 拍板(原样留痕) |
| 分叉 | 立项对话框选源项目+基线版本 | git worktree 检出该版本代码,数据符号链接共享,源项目零改动 |

界面上每个项目卡带**基线徽标**(v 几/EMA-PVL·原始·分叉/日期/分叉自谁),研究页顶部
常驻「对比基线」卡——用户随时知道自己在跟谁比。

## 五、真机战绩:medtest2(MedCLIPSeg 医学图像分割)

第一个完整走通全闭环的真实工程(A6000 共享机,6 个数据集口径):

| 事件 | 结果 |
|---|---|
| Baseline | 6 口径确认:Kvasir 0.903 / BUSI 0.853 / ISIC 0.925 / BTMRI 0.890 / BUSI@10% 0.678 / Kvasir@10% 0.762 |
| 重型研究(4 轮过夜) | Agent 提出 **EMA-PVL**(把 PVL 模块的 30 次蒙特卡洛采样换成解析 EMA 聚合):5-seed 均值 **0.6952 vs 0.6775(+1.8pt)**,4/5 seed 双指标超基线,第 3 轮独立复现;顺带证伪 hflip TTA(少样本有害) |
| 全量验证(6 数据集×1 seed) | Kvasir@10% **+2.7pt ✓** / BUSI@10% **+2.6pt ✓**(少样本假设跨数据集成立)/ Kvasir +0.2 ✓ / BTMRI·ISIC 持平 / BUSI 全量 -1.2 ✗(单 seed 噪声待查) |
| 采纳 | owner 拍板采纳 → 新基线 v2=EMA-PVL(全指标实测均值),v1 入历史 |
| 分叉 | 待演示:从 v1 原始基线 worktree 分叉新方向,秒级、数据零拷贝 |

过程中的真实事故也成了产品改进:轮 1-3 把 BUSI@10% 标成 BUSI 导致判定失明三轮
(→ 标注校验上线);轮 4 一个次优变体的单 seed 冒尖误触发停止(→ 均值判定+冠军追踪上线)。
