# AutoLab 视频大纲(2026-10-27 备稿)

> 用途:为自制视频准备的内容底稿——叙事弧、分镜、素材清单、口播要点、关键数字。
> 本文档只备稿,不做视频。素材均为真实数据(medtest2/EMA-PVL 全程可复放)。

## 0. 定位建议

- **给谁看**:课题组同学/研究者(潜在用户)、对外展示(开源/申请/汇报)
- **时长建议**:3-5 分钟为主片;可另剪 60 秒纯演示版
- **叙事策略**:不按功能清单讲,用**一个真实研究故事贯穿**——medtest2 上 Agent 一夜提出
  EMA-PVL、验证、采纳为基线的全过程。功能都在故事里出现。
- **风格**:屏幕录制为主 + 飞书/手机通知实拍穿插 + 关键数字大字卡

### 第Ⅰ幕 痛点(20-30s)

- 大字卡:「如果有个不用睡觉的你?」

### 第Ⅱ幕 设定(30-40s)

  交给 Agent 自由推进——但它只能用你给的 GPU、按你的基线口径、留下全部证据」

## 5. 可能被问的问题(备口径)

- 「Agent 会不会作弊改评测?」→ 公平对比是硬规则:不得改评测代码/指标定义/数据划分;
  指标必须真实评测;dataset 标注与命令身分参数提交时校验,口径不对直接拒。
- 「单 seed 赢了算数吗?」→ 不算:判定按变体多 seed 均值(重型≥3),seed 不齐判「证据不足」继续。
- 「Agent 把代码改坏怎么办?」→ 改码前强制 git 快照;无效改动可回退;每轮 kept=true/false 留痕。
- 「数据安全?」→ 全部跑在你自己的 GPU 服务器上;shell 有治理黑名单(平台边界/破坏性命令)。
