01LangGraph 图本体:拓扑没变,编译参数变了

graph.get_graph() 官方导出(与上一版完全一致)+ 两个新编译参数

▶ compile(checkpointer=SqliteSaver) 新——每个 super-step 后状态落 agent_checkpoints.sqlite(主 DB 同目录;依赖缺失回落 InMemorySaver,功能不缺席)
▶ interrupt_before=['agent'] 新——每次进入 agent 节点前暂停,把"何时步进"的控制权交给外面的驱动循环
▶ thread_id = session_id 新——同会话重入即从断点恢复,消息历史不丢
▶ START → agent ⇄ tools → END,route() 条件边(有 tool_calls→tools;墙钟≤20s 或无调用→END)不变

02核心变化:外面套了一个"驱动循环"(run_session)

图不再一口气 invoke 到 END——驱动循环每个步进点检查一遍:收工了吗?有人叫停吗?有新指令吗?预算还够吗?
