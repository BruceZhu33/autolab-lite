# 许可状态说明

本交接包用于内部产品设计和新工作区开发，不等同于一个已经完成对外授权的开源发行包。

## AutoLab 自有材料

需求文档、架构文档、协议和新工作区将产生的 AutoLab 自有代码尚未选择正式发布许可证。内部开发可以继续；公开仓库、二进制发布、SaaS 或商业分发前必须由项目所有者明确选择许可证。

## Multica 材料

以下目录含来自 Multica 的材料或派生留档：

- `source-assets/ui-reference/multica-shell-source-reference.tar.gz`
- `source-assets/ui-reference/*.png`

其许可证、NOTICE 和来源记录包含在源码快照内。该许可证不是无附加条件的 Apache 2.0；对托管、商业嵌入、品牌修改和署名有额外要求。除非已经完成 `09-v1.3审查修订与决策门.md` 的 M5 决策，否则这些材料不得进入 AutoLab 产品构建或被重新命名为 AutoLab 品牌资产。

## Any Science Framework

本交接包没有复制 Any Science Framework 的源码或模板，只独立记录了“研究资产文件化、事前判据、人类保持 PI、结论引用证据、失败经验可恢复”等一般产品原则。评估时该仓库未声明开源许可证。
