### 事务层（产品核心——全部从契约 harness 逐字移植）

| 函数 | 契约对应 | 功能 |

| `tx_freeze_batch` | T-FREEZE-BATCH | 批次权威派生（候选/BASE×seed + 消融） |
| `tx_final_read` | T-FINAL-READ | test 一次性释放（不变量②） |
| `tx_baseline_acceptance` | — | D33 基线验收 |
| `tx_drain_reduce` | T-DRAIN | 预算下调两阶段 |

## 六、已知缺口（按优先级——用户裁决）

### 🔴 用户用前必须

1. **真实 LLM key**：设置页 → ② 迭代分析 → Base URL + model + key + 引擎选择（builtin/rdagent）→ 测试连通性
   - 支持任何 OpenAI 兼容端点（智谱/DeepSeek/OpenAI/Ollama）
   - RD-Agent 引擎需要稍大 context（推荐 glm-4.7 / gpt-4o 级别）

### 🟡 功能补全（按用户需求迭代）

2. **M4 全链重验**：SEALED→final-read 最后一步（需大预算项目，事务有单测背书）
3. **per-server 环境映射**：不同服务器用不同 conda 环境名（4090D 没有 traq）
4. **增强冒烟**（A02）：现在是 py_compile，应该跑前向/loss/反向/checkpoint
5. **P6 报告页 UI**：后端就绪（POST /reports → report_dir），页面待接
6. **Tauri 壳编译**：脚手架在 ui/src-tauri/，需要 Rust 工具链
7. **沙箱收紧**（Z1）：systemd transient unit + 三 Unix 用户 + 评测禁外网
8. **外部文献检索**（D42 external）：arXiv/S2 API 查询 + paper-qa RAG

### ⬜ 后置（不阻塞使用）

9. GitHub BASE 来源、GPU 遥测轮询、多项目仲裁、Monaco diff 回放、WS 快照完整协议

## 七、关键操作备忘

```bash
# 一键起停本地三件套
bash scripts/dev_local.sh

# 真机 agent 部署/升级（UI GPU 页也有按钮）
TOKEN=$(cat ~/Library/Application\ Support/AutoLab/capability_token)
curl -X POST http://127.0.0.1:39876/api/v1/servers/{server_id}/agent/install \
  -H "X-Capability-Token: $TOKEN"

# 全量回归
cd sidecar && .venv/bin/python -m pytest tests/ -q \
  --ignore=tests/e2e_m2_reliability.py --ignore=tests/e2e_local.py --ignore=tests/e2e_stop_ws.py
# e2e（真机）：.venv/bin/python tests/e2e_local.py 等

# 契约回归
cd docs/contracts && /tmp/autolab_venv/bin/python tests/run_all.py  # 175/175

# sidecar 手动重启
lsof -ti :39876 | xargs kill; sleep 2
cd sidecar && AUTOLAB_HOME="$HOME/Library/Application Support/AutoLab" \
  AUTOLAB_PORT=39876 AUTOLAB_CRED_STORE=file \
  nohup .venv/bin/python -m autolab > /tmp/autolab-sidecar.log 2>&1 &

# 真机 agent 手动重启（A6000）
ssh serveruser@192.0.2.46
cd ~/autolab-gpu-agent && AUTOLAB_AGENT_TOKEN=<token> PYTHONPATH=$PWD/pylibs \
  setsid nohup ~/anaconda3/envs/traq/bin/python -m autolab_agent --port 7800 \
  > agent.log 2>&1 &
```
