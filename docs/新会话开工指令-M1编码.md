## 二、任务：M1 单机纵切（需求 §7 原文）

> **1 台服务器注册 → 立项 → 远程搭环境 → 手动触发一轮训练并监视、日志回收。打通最硬的 SSH/队列/日志链路。**

具体拆解（建议顺序）：

1. **sidecar 骨架**：FastAPI + SQLite，用 `contracts/schema.sql` + `contracts/sm_transitions.generated.sql`
   建库（migrations/0001_init.sql 可直接执行）；capability token 中间件；`/healthz` + `/api/v1/meta`
2. **服务器注册与连通**：`POST /servers` + SSH 连通性测试（asyncssh）；凭据走 macOS 钥匙串（D48 适配器）
3. **gpu-agent v0**：服务器端 FastAPI 最小实现——`GET /healthz` / `POST /attempts`（dispatch_id 幂等）/
   `GET /attempts/{id}?tail=`（日志尾）；manifest HMAC 签名先做生成与校验函数（agent 侧完整沙箱可后置，
   M1 手动触发场景可先明文跑通再收紧）
4. **立项与环境搭建**：卡池勾选 → conda 环境搭建 → BASE 快照导入 → 数据副本 SYNCING→校验→READY
   （参考 `contracts/tests/harness.py` 的 `fx_replica_ready`——那就是校验链的实现规格）
5. **手动触发一轮训练 + 监视**：`POST /projects/{id}/runs` → T-AUTHORIZE-DISPATCH（抄 harness 的
   `tx_authorize_dispatch`）→ agent 执行 → 日志尾回收 → attempt 状态经 T-INGEST 入库
6. **UI（可用最小面）**：Tauri 壳 + Next 静态导出；M1 只需 P1 服务器页 + P3 立项页 + P5 监视页的
   最简版本；WS 事件先做 3-4 种（project/run/attempt state_changed + 日志尾）

**M1 明确不做**：LLM 改码循环（M2）、评审对话（M3）、消融/多 seed/报告（M4）、
v2.8 提案 ADD-1~4 对应功能（降额终局/子项目/报告实体/评审实体——都不阻塞 M1）。

## 三、契约的定位（重要，上一会话的核心结论）

- 契约 = **参考规格，不是枷锁**。schema.sql / state-machine.yaml / harness 参考实现直接使用；
- **实现与契约冲突时，以实践为准**，把冲突记入 `docs/deviation-log.md`（新建，格式：
  日期 | 契约位置 | 冲突描述 | 实践决定 | 理由），攒批修订契约，**不要**为迁就契约扭曲实现；
- 契约中过重部分允许降级实现（例如 73 个 trigger 里防御纵深的部分，若拖慢迭代，可先建表后补 trigger），
  但**四个核心不变量不许降级**：① 预算 C+R≤B + overage 禁新授权；② test 结果仅
  `final-confirmation/read` 一次性释放；③ dispatch_id/agent 事件幂等；④ 评测正式指标唯一入口；
- 测试套件（`contracts/tests/`，175 项，新位置已验证可跑：`pip install -r contracts/tests/requirements.lock.txt
  && python3 contracts/tests/run_all.py`）是回归资产——sidecar 的核心事务写完后，把 harness 的 tx_*
  测试跑在真实代码上作为验收。

## 四、纪律

- **不再送外部 AI 评审循环**。验收人是用户本人 + 真实运行结果；五轮评审已把架构级问题清零，
  剩余未知风险（RD-Agent 循环能不能转、冒烟通过率、日志分析质量）只能靠实践暴露；
- 架构基线 v2.7 冻结不变；实现中发现设计缺口 → 记 deviation-log → 用户裁决，不擅自改设计；
- 每完成一个纵切段（如"SSH 连通+agent healthz"），在真实服务器上跑一遍再继续下一段；
- git：新工作区从空仓库开始，首次提交即本指令 + docs/。

## 五、背景一句话

科研训练自动化桌面应用：用户给方向/BASE 代码/论文/模块想法 → 对话评审定稿 → 全自动训练迭代
（RD-Agent 提案、产品层掌副作用）→ 终止后评估/消融/多 seed → 自动报告。单用户自用工具，
三平台（mac/win/linux），GPU 服务器仅 Linux。当前处于 M1：打通最硬的链路。
