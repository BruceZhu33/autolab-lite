## 1. 当前有效技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面壳 | **Tauri 2**（Rust） | 三平台产物 .dmg/.msi/.AppImage（D48）；监管 sidecar 生命周期 |
| 前端 | **Next.js（static export）+ shadcn/ui** | 基于 Kiranism starter 改造，Clerk/Sentry 已拆除；视觉基线 = Vercel/shadcn 风格（用户确认）；Monaco 用于 diff 回放 |
| 后端 | **Python 3.12 + FastAPI + SQLite(WAL)** | sidecar 进程，仅绑 loopback 随机端口 + capability token |
| 迭代引擎 | **RD-Agent**（版本锁定，仅作提案引擎） | 产品层掌握全部副作用（设计 §2）；fork 后置 |
| 远程执行 | **gpu-agent**（自研，FastAPI 最小依赖） | 执行清单 HMAC 签名、train/infer/aggregate 三权限域（多 profile）、事件游标对账、agent 自计量、远端硬截止 |
| SSH | **asyncssh** | 命令/SFTP/隧道（D14）；数据同步默认纯 Python SFTP+manifest（rsync 仅 Linux/mac 加速） |
| 配置 | **omegaconf** | 命令模板渲染、消融矩阵展开 |
| LLM | **httpx 薄客户端**（OpenAI 兼容） | 多供应商按使用点配置（D11） |
| 文献 | **paper-qa** + arXiv/S2 API | D4/D42 |
| 图表 | **matplotlib**（服务端）+ ECharts 组件（模板自带） | D28 |

## 2. 技术决策台账（TD，最终态）

TD1'' 前端 Next.js+shadcn/ui（AntD 弃用）· TD2' 产品层循环控制器（引擎不重造、副作用全归产品层）· TD3 全自建追踪（runs/attempt/evaluation_results 表）· TD4 asyncssh · TD5 omegaconf · TD6' RD-Agent 底座（提案引擎化）· TD7 httpx 薄客户端 · TD8 gpu-agent 同栈瘦身 · TD9' 前端两阶段（M1 起即用 shadcn 模板）· TD10 侧栏五入口六模块 · TD11 Clerk/Sentry 拆除 · TD12 Tauri×Next 静态导出 · TD13 Monaco · **TD14 执行身份分离（train / candidate-infer / trusted-aggregate 三 Unix 用户 + root 只读评测资产 + HMAC 签名清单 + test 结果一次性释放）** · **TD15 事务 outbox + 状态 CAS** · **TD16 预算三表账本（accounts/reservations/usage_events）**

## 3. 依赖与许可证

fastapi/uvicorn（MIT）· asyncssh（EPL-2.0，仅 pip 引用不改源，自用无碍）· GitPython（BSD-3）· omegaconf（MIT）· httpx（BSD-3）· paper-qa（Apache-2.0）· matplotlib（宽松）· react/shadcn 生态（MIT/Apache）· RD-Agent（MIT）。系统二进制：git、ssh、nvidia-smi（服务器）；rsync 可选。

## 4. 自建模块清单（不变，九项 + 新增三项）

原九项（评测执行器/预算账本/版本绑定/数据同步/运行隔离/指标采集/消融矩阵/状态机/阶段报告）+ 评审新增：**导入加固**（LFS/子模块/未提交策略，B5）、**执行清单组装器**（digest，B6）、**平台适配器层**（文件锁/进程/凭据，D48）。

## 5. 已知权衡（现行）

1. 评测隔离用"三 Unix 用户 + OS 权限 + HMAC 清单"，非容器/VM——自用威胁模型下接受，不防内核级（升级路径 = 优先隔离 candidate-infer 域，其次 agg）。
2. RD-Agent 版本锁定换取适配器契约稳定，升级需显式重评。
3. asyncssh EPL-2.0：自用无碍；商业化再评估替换。
