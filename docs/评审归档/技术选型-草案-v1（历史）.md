## 1. 选型总览

| 层 | 选型 | 关键理由 | 对应需求 |
|---|---|---|---|
| 后端框架 | Python 3.11 + FastAPI + Uvicorn | 异步原生（并发监视多服务器）、自动 API 文档、pydantic 校验 | D2 独立 Web UI、[0]–[7] 全部 |
| 存储 | SQLite（WAL 模式） | 单用户零运维；预算账本/轮次/版本绑定直接建表，断点恢复友好 | D31 D32 D38 D40 |
| SSH 层 | asyncssh | 命令执行 + SFTP + **端口转发**一库解决；D14 隧道通信是硬需求 | D14 D16 D31 |
| git 操作 | GitPython | 链式 commit、diff 提取、检查点、分支管理 | D10 D19 D40 |
| 配置内核 | omegaconf | 命令模板渲染 + 消融矩阵展开，只要内核不要 Hydra CLI | A01 D36 |
| LLM 接入 | httpx 薄客户端（OpenAI 兼容协议） | 多供应商可配、重试/退避自己控（要配合 D41 失败分类） | D11 D41 |
| 文献 RAG | paper-qa | 引用式科学文献问答，正好做 [3] 文献对照 | D4 D17 D42 |
| 外部检索 | arXiv API + Semantic Scholar API（httpx 薄封装） | D42 双模式中的"外部检索"档 | D42 |
| 前端 | React 18 + Vite + TypeScript + **Ant Design 5** + ECharts + TanStack Query | 后台型产品，AntD 的表格/时间线/表单组件密度高；ECharts 画曲线 | P1–P7 |
| 科研静态图表 | matplotlib | 服务端出 PNG/SVG/PDF + 数据源文件 | D28 |
| 迭代引擎 | **自研轻量状态机**（asyncio + SQLite 持久化） | 7 个状态、绑定关系用表表达最直接可审计 | D32 D38 D45 |
| 实验追踪 | **全自建**（runs 表 + ECharts） | D40 四类版本绑定反正要自建；少一个常驻服务 | D40 Q01 |

**gpu-agent（服务器端）**：Python + FastAPI + sqlite3（stdlib），解析 nvidia-smi、一卡一队列（D15）、进程组管理与日志落盘、**独立预算/截止执行**（D32/R02——控制端失联也要能停）。无重依赖，pip 装完即跑。

**数据同步**：系统 rsync（二进制，Mac/Linux 均预装）做传输 + 自建 manifest（文件清单 + sha256）做版本校验与原子发布（D39）。

## 4. 依赖与许可证清单

**后端（本机）**：fastapi、uvicorn、asyncssh（EPL-2.0 ⚠ 唯一弱 copyleft，作 pip 库引用不改源码，自用无碍）、GitPython（BSD-3）、omegaconf（MIT）、httpx（BSD-3）、paper-qa（Apache-2.0）、matplotlib（Matplotlib License，宽松）、pydantic v2、pyyaml。
**前端**：react、antd（MIT）、echarts（Apache-2.0）、@tanstack/react-query（MIT）、vite（MIT）。
**gpu-agent（服务器）**：fastapi、uvicorn，其余全 stdlib。
**系统二进制依赖**：rsync、git、ssh、nvidia-smi（服务器）——全部预装，无额外安装。

## 5. 与里程碑的对应

- **M1 单机纵切**：FastAPI 骨架 + SQLite + asyncssh + gpu-agent 最小版（一卡一队列 + 日志回收）+ React 壳。此阶段不涉及 LLM。
- **M2 自动闭环**：状态机 + LLM 薄客户端 + 冒烟 + 自修复 + 预算账本 + 单机可靠性验收（取消竞态/断线对账/失败重试）。
- **M3 评审与文献**：paper-qa + arXiv/S2 检索 + 对话式评审 UI。
- **M4 科研标准流程**：评测执行器 + 消融矩阵 + 两门槛多 seed + 图表包 + 阶段报告 + 跨机验收。

## 6. 已知权衡（记录在案）

1. **自研状态机/追踪**换来完全可控与可审计，代价是放弃框架的现成检查点——用 SQLite 持久化补齐，且 D31 断点恢复本来就要自建。
2. **asyncssh 的 EPL-2.0**：仅 pip 依赖不改源码，自用产品无合规问题；若将来商业化可换 fabric（BSD）+ 手工隧道。
3. **不引 Docker**（D30 资产保护用文件权限 + 目录隔离实现）：自用场景够用，服务器也不用装 docker。

## 9. 修订记录三（2026-09-12 · 跨平台，D48）

- **目标平台**：macOS / Windows / Linux 三平台安装包（D48 用户仲裁）。
- **构建**：CI 矩阵构建（Tauri 各平台产物：.dmg / .msi / .AppImage）；sidecar 用 PyInstaller 按平台打包。
- **rsync 降级为可选优化**：默认走纯 Python 同步（asyncssh SFTP + manifest 校验和），Linux/mac 有 rsync 时提速用——保证 Windows 开箱即用。
- **红线**：所有代码禁用平台专属 API（路径用 pathlib、进程用跨平台抽象、无 macOS/Windows 专属依赖）。
